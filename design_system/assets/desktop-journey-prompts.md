# Desktop journey assets

Generated with the built-in imagegen tool on 2026-11-11. Local copies are compressed for web use. No external reference artwork or credentials were used. Historical hardware is illustrative, not documentary product photography. The earlier Macintosh image is retained as an unused study; the landing starts with MacBooks.

## Common photograph direction

Product mockup for a premium website showing MacBooks through the years. One laptop, open approximately 100 degrees, symmetric straight-on front camera slightly elevated to show the keyboard. Landscape 1536 by 1024 framing, whole laptop centered with clear padding. Soft neutral diffused studio lighting, authentic materials, genuinely transparent background. No accessories, cables, hands, desktop surface, text, labels or watermark. Screens contain period-inspired blue artwork, without readable text or windows. HTML supplies an authentic Terminal window with source-derived CLI output.

## Final prompt set

- `macbook-2006.webp`: original white polycarbonate MacBook, thick white display surround, white chiclet keyboard, small rectangular trackpad, blue Mac OS X Tiger-style aurora and period dock.
- `macbook-air-2010.webp`: second-generation silver aluminum MacBook Air, thin tapered wedge, silver display surround, black keyboard, glass trackpad, blue Mac OS X Snow Leopard-style aurora and reflective dock.
- `macbook-retina-2015.webp`: silver 13-inch Retina MacBook Pro, black display bezel, black keyboard, silver trackpad, blue and slate Yosemite-inspired mountain wallpaper.
- `macbook-modern.webp`: contemporary 14-inch space-black MacBook Pro, thin black display border, camera notch, black keyboard, blue optical-glass wave wallpaper and translucent dock.
- `glass-wave.jpg`: original expansive blue liquid optical-glass ocean wave, pale sky, sapphire folds, soft ivory highlights, precise caustics. No hardware, windows, interface, text, logos, purple, pink or neon. Wide composition, quiet central region for real HTML windows.
- `classic-mac-cutout.webp`: unused earlier study of an ivory compact 1984 Macintosh, keyboard and mouse. A second imagegen pass removed the studio background while preserving the device framing.

## Film

`desktop-film.mp4` is a deterministic 12.6-second illustration composed from the original wallpaper and SVG Terminal layers by `scripts/render-desktop-film.py`. The contemporary frame uses rounded corners, a translucent title bar and circular red/yellow/green controls. It reveals the seven actual dry-run stages inside Terminal over the blue wallpaper. It is not AI-generated footage or a recording of an actual update. The script also creates `desktop-film-poster.webp`.

`terminal-preview.webp` is the source-derived final film composition, not a screenshot of an actual update of the host. Generated laptops supply only the hardware and wallpaper. All tool output is rendered as real text, using the CLI source rather than image generation.
