# macOS Updates workshop redesign

The owner approved the combination of Bryan's Garage, Webdrift, The Watch and CoffeeTech on 2026-11-13. Build an original identity around a quiet technical workshop: one Mac, many update sources, one inspectable command. The toolkit remains a free open-source Terminal tool.

## Visual direction

Use graphite, silver and the existing GO blue. Keep amber exclusively for HOLD. Manrope carries large, closely set headlines; IBM Plex Mono carries real commands. All color, shape, font and shadow tokens remain in `src/index.css`. Native Mac windows retain their approved rounded-frame exception. Other controls keep 2px corners, no shadows and 44px minimum targets.

The opening is a full-width original Mac photograph with asymmetric type and visible install action. A switch between a historical CRT scene and a modern workstation produces a short deliberate screen-close/reopen transition. Historical hardware is a visual reference, never a compatibility promise. Narrow screens show the complete artwork with text below it.

## Journey

1. Recognition: a large Mac photograph and the message that software maintenance should leave time for work.
2. Contrast: switch historical and current scenes; explain that the toolkit supports modern Apple Silicon Macs.
3. Proof: a dedicated native Terminal chapter with verified seven-language dry-run messages, finite play/pause/replay, and a clear demonstration label.
4. Understanding: selectable stages explain preview, vendor verification and controlled updates. Keep the app registry searchable and its counts centralized.
5. Relief: a quiet original office photograph, copyable install command, documentation and optional one-time support.

The distinct interaction is the CRT era switch. It is user-triggered, reversible, focus-preserving and disabled for reduced motion. Avoid scroll locking, forced snapping and infinite animation. The logo is an original interrupted update ring that resolves into an upward action/check sequence; compact versions remain static.

## Payments and integrity

Provide a localized support route with validated external hosted links. Revolut is available from the owner's existing public support configuration. Stripe is available only when real currency-specific hosted URLs are configured. No simulated payment success, card collection, invented BLIK promise or new backend. Source version, latest release and test collection evidence remain distinct. Preserve lazy route loading, SSG, localized metadata and sitemap parity.

## Validation

Run lint and full build. Inspect desktop and mobile composition, all route links, menu keyboard behavior, terminal lifecycle, copying, era switching, logo states and reduced-motion behavior. Verify generated assets before shipping and document their prompts. No publication or public-history rewrite is included in local implementation approval.
